# Veikkausohjelma

A JavaFX sports prediction application backed by SQLite.

Extracted from [ppv10/Projects](https://github.com/ppv10/Projects/tree/main/Guessing%20program%20JavaFX%20project%20(Finnish)). Generated Maven output and the local database file were intentionally left out.

Build or run with Java 17 and Maven:

```sh
mvn clean javafx:run
```
